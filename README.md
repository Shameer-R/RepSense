# RepSense - Exercise Recognition Using Machine Learning
RepSense is a machine learning project that aims to recognize different exercises using wearable sensor data.

## Project Overview
The goal of this project is to train and evaluate machine learning models that can identify exercises based on accelerometer, gyroscope, and capacitive sensor readings.

## Dataset
The dataset contains approximately 4.7 million sensor readings across multiple exercise types

Features include:
- Accelerometer readings (X, Y, Z)
- Gyroscope readings (X, Y, Z)
- Capacitive sensor readings
- Workout labels
- Recording metadata
